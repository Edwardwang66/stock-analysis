# 完整因子测试体系 × 加密(`crypto_pipeline.py`)

> **Status:** Historical research snapshot; not maintained
> **Scope:** Dated research result preserved for methodology and provenance, not current product behavior.

把股票那套体系(去极值/标准化/**中性化** → IC/IR → 分层 → 无未来函数验证)接到 Hyperliquid 永续因子上。
加密无 GICS 行业,故按 Liu-Tsyvinski-Wu"市场+规模+动量"框架,**中性化对象 = size(log 日均成交额)+ BTC-beta(市场暴露)**。
周频 rebalance(step=7)、周持有(H=7),20 币,205 期。

`mom_14` 分层周收益:L1 −0.36% / L2 +0.03% / L3 −0.83% / L4 +0.71% / **L5 +2.59%**(顶层很强,中段非单调)。

### 中性化做了什么(这是这套体系最大的价值)
1. **vol_20 被"打回原形"**:原始 IC 0.082 很亮眼,中性化后塌到 0.018 ——
   它的"低波 alpha"**几乎全是 BTC-beta(市场暴露)**,而非真 alpha。剔除市场暴露后就没了。
   → 这正是中性化的意义:**挤掉风格/市场水分,暴露假因子。**
2. **mom_14 反而变强**(0.045 → 0.052,过了 IC>0.05 线):动量**不是**规模/市场的伪装,是真信号。
3. fund_carry 中性化后由负转微正,basis/reversal 仍弱:这些独家信号在本短样本+震荡 regime 下没跑出来。

### 诚实判定(对照你给的阈值 IC>0.05、IR>0.5)
- **只有 mom_14 过了 IC>0.05**,但 **IR 仅 0.18(<0.5)**、分层非单调、回撤 −35%、毛 Sharpe 1.88 但未扣成本。
- 加密横截面只有 ~15-20 币,5 分层每层 3-4 币,**统计噪声极大**;且 Hyperliquid 仅 ~2-4 年(违反 MinBTL)。
- 结论:**动量是加密里最接近"真"的因子,但远未达到可下重注的稳健度(IR 不达标 + 样本太短)。**

## 无未来函数验证:最近 4 周(≈1 月)滚动样本外

固定 mom_14 方向,逐周用"当时及之前"数据建仓持有 7 日:

```
2026-05-07  多空 -1.48%   L5 +0.52%    BTC +1.32%
2026-05-14  多空 -3.02%   L5 +8.07%    BTC -4.27%
2026-05-21  多空 -2.24%   L5 -10.18%   BTC -5.16%
2026-05-28  多空 +36.15%  L5 +27.96%   BTC -13.23%
均值 +7.35%/周   胜率 25%
```

**最重要的一课(比股票更触目):**
- 均值 +7.35%/周看似惊艳,**胜率却只有 25%** —— 4 周里 3 周亏,全靠一周 +36% 的尾部撑起。
- 加密**肥尾**让小样本均值彻底失真:**n=4 毫无统计意义**,挑任何一周都能讲出完全相反的故事。
- 全期 Sharpe 1.88 是 205 期的估计,才有参考价值;但即便如此,IR 0.18 说明**逐期高度不稳**。

## 与 `README_crypto.md` 的关系
- `README_crypto.md`:做了**因子合成 + 拟合(Ridge/Purged walk-forward)**,结论是短样本过拟合、正 IC 未 translate 成 P&L。
- 本文(`crypto_pipeline.py`):做了**标准预处理 + 中性化 + 单因子分层**,结论是**中性化暴露了 vol_20 是 beta 假因子、动量是唯一过 IC 线的真因子**,但 IR/样本量仍不达可投标准。
- 两者一致指向同一诚实结论:**加密有真信号(动量),但当前数据长度与横截面宽度不足以稳健落地;需要更长历史(接 Binance/Bybit)+ 历史 OI + CPCV/Deflated Sharpe 才能定论。**
