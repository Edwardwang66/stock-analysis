# 加密多因子研究 + 拟合(Hyperliquid 永续)

> **Status:** Historical research snapshot; not maintained
> **Scope:** Dated research result preserved for methodology and provenance, not current product behavior.

按研报 §3/§6 实现的**加密横截面多因子模型**,并按你的要求"先手配权重、最后做拟合"。
数据:Hyperliquid `info` API,20 个流动性最高的永续币,日线最多 4 年、资金费最多 2 年,无未来函数。

> **一句话结论(诚实):加密因子有股票没有的正交信息(funding/basis/低波),单因子 Rank-IC
> 比股票高一截(vol_20 达 0.12、mom_14 达 0.05);但在仅 ~2 年的短样本上,拟合权重会过拟合
> ——拟合模型 Rank-IC 最高却 P&L 最差(Sharpe −0.83),且没有任何组合跑赢"等权持有全部币"。
> 这不是因子无效,而是数据太短 + 当前是回撤/震荡 regime,正好撞上研报警告的所有坑。**

## 因子(`crypto_factors.py`,Hyperliquid 独家正交信息)

| 因子 | 定义 | 理论方向 | 依据 |
|---|---|---|---|
| `mom_14` | 过去 14 日收益(跳过最近 2 日) | + | 加密动量 1-4 周最强(Liu-Tsyvinski-Wu) |
| `reversal_3` | 过去 3 日收益 | − | 短期反转 |
| `vol_20` | 过去 20 日年化波动 | − | 低波 |
| `fund_carry` | 过去 7 日"日资金费之和"均值 | − | **高 funding=多头拥挤=看空(股票没有)** |
| `basis` | 过去 7 日 premium 均值 | − | **perp-spot 溢价拥挤(股票没有)** |

## 结果一:Rank-IC(`crypto_backtest.py`,多周期)

| 因子 | H=1日 | H=7日 (t) | H=30日 (t) |
|---|---|---|---|
| mom_14 | +0.008 | +0.046 (2.1) | +0.052 (3.0) |
| reversal_3 | −0.020 | −0.031 (−1.3) | −0.041 (−2.1) |
| **vol_20**(低波) | +0.030 | **+0.089 (3.5)** | **+0.123 (4.9)** |
| fund_carry | +0.002 | −0.015 | −0.024 |
| basis | +0.005 | −0.007 | −0.018 |
| 合成(等权) | +0.020 | +0.035 | +0.036 |
| 合成(手配 HAND_WEIGHTS) | +0.001 | +0.010 | +0.006 |
| **合成(拟合/OOS Ridge)** | −0.013 | **+0.068 (2.6)** | **+0.071 (3.0)** |

- **单因子 Rank-IC 比股票高**(vol_20 0.12 vs 股票最强 reversal 0.035):加密信号更强、噪声也更大。
- **拟合(Purged walk-forward Ridge,样本外)Rank-IC ≈ 0.07,几乎是等权的 2 倍、手配的 7-10 倍** ——
  数据驱动的拟合确实学到了"重仓低波+动量",**比我手配的权重好得多**(手配高估了 funding/反转、低估了低波)。
- ⚠️ 但这些 t 值被**重叠样本**(step=3 / H=30 → 10× 重叠)夸大,有效独立样本只有 ~24。

## 结果二:可交易性 —— 正 Rank-IC 没有 translate 成 P&L(`crypto_pnl.py`)

非重叠月度、tertile 长短组合(做多高分 1/3、做空低分 1/3),24 个月:

| 信号 | 低分组 | 中 | 高分组 | L/S Sharpe | 胜率 |
|---|---|---|---|---|---|
| 拟合(OOS Ridge) | **+8.6%** | +3.0% | +4.3% | **−0.83** | 41% |
| 低波 vol_20 | +4.6% | +1.8% | +1.9% | −0.52 | 42% |
| 动量 mom_14 | +4.5% | +2.0% | +2.4% | −0.33 | 62% |
| 等权合成 | +3.4% | +0.9% | +3.9% | +0.10 | 62% |
| **基准:等权持有全部币** | — | — | — | **+0.35** | — |

**这是整个项目最重要的一课:**
- **每个信号的"低分组"未来收益反而最高** → 正的 Rank-IC 来自中段弱正序,**两端是反的(非单调)**,不可交易。
- **拟合模型 Rank-IC 最高,P&L 却最差(Sharpe −0.83)** —— 它在短样本上重仓 `vol_20(+0.46)`、`fund_carry(−0.41)`,样本外这些集中押注全错。**这是教科书级的过拟合**(研报 §5.3:5 年/45 配置即几乎保证过拟合;此处样本更短)。
- 谁都没跑赢"无脑等权持有全部币"(Sharpe +0.35)。

平均拟合权重(Ridge 学到的载荷):`vol_20 +0.46`、`fund_carry −0.41`、`mom_14 +0.21`、`reversal_3 −0.20`、`basis +0.17`。

## 为什么会这样(对照研报,不是 bug)

1. **样本太短**:Hyperliquid 仅 ~2-4 年,非重叠月度 ~24 个 → 违反 Minimum Backtest Length(研报 §5.3),拟合 5 因子必然过拟合。
2. **regime 依赖**:这段是加密回撤/震荡期(样本内 BTC 大幅下行),动量/低波被均值回归反转 —— 正是研报 §3.4"加密动量有严重 crash 尾部"。
3. **重叠样本**夸大 t 值;有效自由度远小于名义期数。
4. **正 Rank-IC ≠ 可交易**:非单调时,秩相关为正但长短为负(本项目实证)。

## 复现
```bash
cd backtest && pip install -r requirements.txt
python cryptodata.py        # 抓 Hyperliquid 日线 + 资金费(分页)到 crypto_cache/
python crypto_backtest.py   # Rank-IC 多周期 + 等权/手配/拟合(Purged walk-forward Ridge)
python crypto_pnl.py        # 可交易性诊断:分层单调性 + 长短 Sharpe + 学到的权重
```

## 怎样才可能让它真正有效(诚实路线,非保证)
- **更长样本**:接 Binance/Bybit 历史(可回溯到 2017-2020),把独立样本从 24 提到几百,才够拟合。
- **历史 OI 时间序列**(本项目只有 funding/basis;OI 变化 + funding 极值的"拥挤反转"是更强的独家信号,需自建 WebSocket 落库)。
- **regime 切换**:用 BTC 200 日线把趋势/震荡分开,分 regime 拟合(注意这又增加自由度,须用 CPCV 控过拟合)。
- **扣交易成本 + 换手约束**后再评估;最终组合用 **CPCV + Deflated Sharpe** 做过拟合校验,新因子门槛 t>3。
